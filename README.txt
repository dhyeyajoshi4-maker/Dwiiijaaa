# Dwija — interactive love-page template

This is a standalone website inspired by the pink interactive page in the reference video.

## Customize
1. Open `index.html`.
2. Replace the messages with your own.
3. Put your photo at `assets/your-photo.jpg`.
4. Put an MP3 at `assets/music.mp3` if you want the music button to work.

## Test
Open `index.html` in Chrome.

## Put it online
Upload the folder to any static website host (for example GitHub Pages, Cloudflare Pages, Netlify, or Vercel) and share the resulting link.

The template uses original wording and a similar interaction/design rather than copying the reference video's exact text.
